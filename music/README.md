# REV Music files

فایل‌های صوتی‌ای را که REV مجاز به پخش آن‌هاست، در این پوشه قرار دهید؛ برای مثال `music/drive-01.mp3`.

سپس فایل `music-tracks.json` را به این شکل به‌روزرسانی کنید:

```json
{
  "tracks": [
    {
      "title": "عنوان آهنگ",
      "artist": "نام هنرمند",
      "src": "./music/drive-01.mp3"
    }
  ]
}
```

- فقط فایل‌هایی را اضافه کنید که مجوز پخش و میزبانی آن‌ها را دارید.
- مسیر `src` باید به فایل میزبانی‌شده در همین سایت REV اشاره کند.
- پخش‌کننده در صفحه نقشه و هنگام فعال بودن مسیریابی نمایش داده می‌شود.
- نسخه فعلی پخش‌کننده کاتالوگ را از `music-tracks.json` می‌خواند؛ بارگذاری فایل از داخل پنل مدیریت هنوز پیاده‌سازی نشده است.
