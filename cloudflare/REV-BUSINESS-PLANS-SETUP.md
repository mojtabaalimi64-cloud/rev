# راه‌اندازی پلن‌های کسب‌وکار REV

این تغییرات در مخزن GitHub آماده شده‌اند؛ برای اعمال دسترسی‌ها در سرویس زنده، migration دیتابیس و Worker نیز باید منتشر شوند.

## ۱) اجرای SQL در Cloudflare D1
1. Cloudflare را باز کنید و وارد Workers & Pages → D1 SQL database → rev-db → Console شوید.
2. فایل rev-business-plan-entitlements.sql را از همین پوشه باز کنید.
3. تمام دستورات SQL را در Console اجرا کنید. این فایل جدول اختصاص پلن، وضعیت پرداخت، تاریخ شروع/انقضا و امکانات را می‌سازد.
4. اجرای migration باید بعد از ساخته‌شدن جدول rev_business_profiles انجام شود. داده‌های قبلی حذف نمی‌شوند.

## ۲) انتشار Worker احراز هویت
1. در Cloudflare به Worker با نام/آدرس rev-auth-api بروید.
2. نسخه فعلی را قبل از جایگزینی نگه دارید.
3. محتوای فایل rev-auth-worker.js را جایگزین کد Worker کنید و Deploy بزنید.
4. binding دیتابیس باید همچنان با نام DB به دیتابیس rev-db متصل باشد و Secret با نام ADMIN_TOKEN حفظ شود.
5. بعد از Deploy، مسیر /api/health و سپس صفحه مدیریت کسب‌وکارها را آزمایش کنید.

## ۳) مدیریت پلن
- از پنل اصلی REV روی «پلن و بررسی کسب‌وکارها» بروید یا صفحه admin-businesses.html را باز کنید.
- توکن مدیریتی همان ADMIN_TOKEN تنظیم‌شده در Worker است.
- برای هر کسب‌وکار، پلن، وضعیت اشتراک، وضعیت پرداخت، تاریخ انقضا و امکانات مجاز را انتخاب و ذخیره کنید.
- پلن فقط زمانی دسترسی فعال می‌دهد که وضعیت آن «فعال»، پرداخت «پرداخت‌شده» یا «رایگان/معاف»، و تاریخ انقضا در آینده باشد.
- برای پلن رایگان، وضعیت پرداخت را «رایگان/معاف از پرداخت» انتخاب کنید.
- ثبت محصولات فروشگاه از سمت سرور فقط با قابلیت «مدیریت فهرست محصولات» در پلن فعال مجاز است. Worker نیز درخواست را بررسی می‌کند.

## نکته درباره پرداخت
این نسخه وضعیت پرداخت را برای ثبت دستی مدیر نگه می‌دارد؛ درگاه پرداخت خودکار به این پلن‌های کسب‌وکار وصل نشده است. گزینه «پرداخت‌شده» را فقط پس از تأیید واقعی پرداخت انتخاب کنید.
