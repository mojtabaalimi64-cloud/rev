# راه‌اندازی امتیازدهی عمومی REV

این سرویس جدا از Worker فعلی `rev-api` است و جایگزین آن نمی‌شود.

## ۱) ساخت جدول‌ها
در Cloudflare → Storage & databases → D1 → دیتابیس `rev-db` → Console، تمام محتوای فایل `rev-ratings-schema.sql` را اجرا کنید.

## ۲) ساخت Worker
1. در Workers & Pages یک Worker جدید با نام دقیق `rev-ratings-api` بسازید.
2. محتوای فایل `rev-ratings-worker.js` را کامل جایگزین کد Worker جدید کنید و Deploy بزنید.
3. در Settings → Bindings یک D1 database binding اضافه کنید: Variable name برابر `DB` و Database برابر `rev-db`.
4. در Variables تنظیم کنید: `ALLOWED_ORIGINS` = `https://mojtabaalimi64-cloud.github.io`
5. آدرس `/api/health` را باز کنید؛ باید `success:true` نمایش داده شود.

## ۳) بررسی
پس از انتشار سایت، از صفحه برنامه‌ریز سفر برای یک ایستگاه ۱ تا ۵ ستاره ثبت کنید. سرویس میانگین و تعداد رأی‌ها را از D1 می‌خواند و محاسبه می‌کند.

## نکات ضدتقلب و محدودیت
- هر مرورگر برای هر مورد فقط یک رأی ثبت می‌کند؛ شناسه رأی در localStorage می‌ماند و در دیتابیس فقط هش آن ذخیره می‌شود.
- محدودیت نرخ سمت سرور بر اساس IP اعمال می‌شود.
- این روش ورود/احراز هویت نیست؛ پاک‌کردن داده مرورگر یا استفاده از دستگاه/IP دیگر می‌تواند محدودیت رأی تکراری را دور بزند. برای جلوگیری قوی‌تر باید رأی‌دهنده حساب تأییدشده داشته باشد.
