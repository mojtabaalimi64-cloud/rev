سرعت از GPS گوشی تخمین زده می‌شود و ممکن است خطا داشته باشد. شتاب و ترمز شدید فقط نشانه‌های احتمالی‌اند، نه ارزیابی قطعی راننده.

انرژی محاسبه‌شده از درصد شارژ، تخمینی است و به ظرفیت واقعی باتری، دما و کالیبراسیون خودرو بستگی دارد.

اتصال OBD / API خودرو

آماده بررسی سازگاری
